# Tema Ánfion para Hugo

Tema moderno, limpio y de alto rendimiento basado en **Tailwind CSS**, diseñado específicamente para estudios de arquitectura, estándar Passivhaus, bioconstrucción y rehabilitación energética.

## Características

- **Diseño Arquitectónico Minimalista**: Paleta cálida de piedra, arena y antracita, con tipografía Cormorant Garamond e Inter.
- **Galerías Fotográficas con Lightbox**: Visor a pantalla completa con navegación por teclado (`Esc`, `←`, `→`), contador y pies de foto técnicos completos.
- **Filtros Interactivos**: Clasificación de obras por categorías (Casas Pasivas, EnerPHit, Bioclimática).
- **Ficha Técnica Passivhaus**: Visualización de demanda energética ($\le 15\text{ kWh/m}^2\text{a}$), hermeticidad $n_{50}$, valores de transmitancia $U$ y ventilación con recuperación.
- **Menú Responsive**: Cabecera sticky con desenfoque de fondo y menú móvil desplegable.

## Creación de Proyectos

```bash
hugo new content projects/nuevo-proyecto.md
```

Consulta el [README principal](../../README.md) para la guía completa de configuración de galerías y desarrollo.
